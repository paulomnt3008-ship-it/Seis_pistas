Cómo lo implementé

Una sola gsap.timeline() encadena tres tramos: las barras crecen en cascada, la palabra entra letra por letra al mismo tiempo ('<') y todo se asienta con una ease elástica. El slider escribe tl.progress() y el contador traduce ese progreso a fotogramas. La línea verde inferior avanza con tu scroll gracias a ScrollTrigger en modo scrub.

const tl = gsap.timeline({ paused: true });
tl.from(bars, { scaleY: .05, stagger: .06 })
  .from(letters, { yPercent: 120,
         stagger: .05 }, '<')
  .to(bars, { scaleY: i => alturas[i],
         ease: 'elastic.out(1,.4)' });

scrub.oninput = e =>
  tl.progress(e.target.value / 1000);
