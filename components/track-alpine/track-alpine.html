3 elementos en el estado

Este panel solo existe mientras open sea verdadero. Alpine aplica las clases de entrada y salida, y Tailwind aporta las utilidades que animan.

Cómo lo implementé

Alpine no anima la inserción de elementos en un x-for, así que cada tarea nace con shown: false y se activa en el siguiente tick. Eso dispara x-transition. Para quitar, primero oculto y después elimino del arreglo cuando termina la salida. El estado vive en su propio módulo JS, registrado con Alpine.data().

// track-alpine.js
Alpine.data('tareas', () => ({
  add() {
    const item = { id, text, shown: false };
    this.items.push(item);
    this.$nextTick(() => item.shown = true);
  }
}));
<!-- track-alpine.html -->
<div x-data="tareas">
