Movimiento que depende del estado

Alpine.js

3.14.1 · x-transition

Reactividad declarativa en el HTML. Cuando un dato cambia, el elemento entra o sale animado sin código imperativo.

Cómo lo implementé

Alpine no anima la inserción en un x-for, así que cada tarea nace con shown: false y se activa en el siguiente tick. Eso dispara x-transition. Para quitar, primero oculto y después elimino del arreglo cuando termina la salida.

El estado vive en su propio módulo, registrado con Alpine.data().

  • x-transition
  • x-for
  • $nextTick

3 elementos en el estado

Este panel solo existe mientras open sea verdadero. Alpine aplica las clases de entrada y salida, y Tailwind aporta las utilidades que animan. 
// track-alpine.js
Alpine.data('tareas', () => ({
  add() {
    const item = { id, text, shown: false };
    this.items.push(item);
    this.$nextTick(() => item.shown = true);
  }
}));
