Cómo lo implementé

La pelota de arriba se mueve con element.animate(), la versión en JavaScript de las animaciones CSS. Cambiar la curva solo cambia el parámetro easing. La pelota que rebota es CSS puro: un @keyframes que aplasta y estira desde la base, el principio clásico de squash and stretch.

/* rebote: aplastar al tocar el suelo */
@keyframes bounce {
  0%, 100% { transform: scale(1.35, .65); }
  50%      { transform: translateY(-74px); }
}
// WAAPI: misma animación, controlada desde JS
ball.animate(
  [{ transform: 'translateX(0)' },
   { transform: `translateX(${d}px)` }],
  { duration: 1200, easing, fill: 'forwards' });
