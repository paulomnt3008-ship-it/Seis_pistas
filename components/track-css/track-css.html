Cómo lo implementé

El disco es un fenaquistiscopio de 1833 dibujado en SVG: doce dibujos de una pelota alrededor del borde. Gira con element.animate() y easing: steps(12), así avanza exactamente un dibujo por paso y la pelota rebota. El control de fotogramas por segundo cambia playbackRate sin reiniciar el giro.

Abajo, la pelota recorre el riel con la curva que elijas, y la que rebota es CSS puro, con squash and stretch desde la base.

// El disco: un dibujo por paso
const giro = disco.animate(
  [{ transform: 'rotate(0)' }, { transform: 'rotate(-360deg)' }],
  { duration: 1000, iterations: Infinity, easing: 'steps(12)' });

// 12 dibujos en 1 s = 12 fps; el control escala la velocidad
fps.oninput = () => giro.updatePlaybackRate(fps.value / 12);

/* La pelota que rebota: CSS puro */
@keyframes bounce {
  0%, 100% { transform: scale(1.35, .65); }
  50%      { transform: translateY(-70px); }
}
