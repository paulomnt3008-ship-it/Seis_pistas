Anime.js

3.2.2 · stagger en rejilla

Ligera y expresiva. La uso cuando el efecto depende de la posición de muchos elementos, o para dibujar trazos SVG.

Cómo lo implementé

La rejilla se genera según el ancho disponible. Al tocar un punto, anime.stagger calcula el retraso de cada uno según su distancia en la rejilla al punto tocado, y eso produce la onda.

La línea de abajo se dibuja animando strokeDashoffset después de cada onda.

  • anime.stagger({ grid })
  • setDashoffset
  • keyframes
Toca cualquier punto 
anime({
  targets: dots,
  scale: [{ value: .2 }, { value: 1 }],
  translateY: [{ value: -12 }, { value: 0 }],
  delay: anime.stagger(45, {
    grid: [cols, rows],
    from: indiceTocado
  })
});
