Cómo lo implementé

La rejilla se genera según el ancho disponible. Al tocar un punto, anime.stagger calcula el retraso de cada punto según su distancia en la rejilla al punto tocado, y eso produce la onda. La línea de abajo se dibuja animando strokeDashoffset después de cada onda.

anime({
  targets: dots,
  scale: [{ value: .2 }, { value: 1 }],
  translateY: [{ value: -12 }, { value: 0 }],
  delay: anime.stagger(45, {
    grid: [cols, rows],
    from: indiceTocado
  })
});
