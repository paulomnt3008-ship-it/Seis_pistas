Cuándo uso cada una

Elijo la herramienta según el problema, no según la moda. Esta es la regla que sigo con cada una.

CSS

Para lo simple: loops, hovers y cargas. Si el navegador lo resuelve, no cargo nada.

Tailwind

Para los estados de un componente, escritos junto al diseño: hover, foco y carga.

GSAP

Para secuencias: muchos elementos en orden, con traslapes y un timeline que se puede arrastrar.

Anime.js

Para patrones: ondas que recorren una rejilla y trazos SVG que se dibujan solos.

Three.js

Para profundidad: escenas en WebGL cuando el plano ya no alcanza.

Alpine

Para cuando el movimiento depende de datos: algo entra o sale porque cambió el estado.
