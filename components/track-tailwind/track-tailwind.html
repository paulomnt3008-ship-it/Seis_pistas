Tailwind CSSv3.4 · transition-* · animate-* · group-hover

Tailwind describe el movimiento en el mismo lugar que el diseño. Ideal para estados de hover, foco y carga dentro de componentes, sin escribir CSS aparte.

  • group-hover
  • duration-500
  • ease-[…]
  • keyframes en config
PASA EL CURSOR O ENFOCA CON TAB
animate-ping animate-wobble (propio) animate-bounce

Cómo lo implementé

Cada tarjeta es un group; los hijos reaccionan con group-hover: y group-focus-visible:, así el teclado ve lo mismo que el mouse. La curva con rebote es un valor arbitrario, y animate-wobble es un keyframe que registré en tailwind.config. Desactivé el preflight para que Tailwind conviva con el resto de la página.

// js/config/tailwind.config.js
theme: { extend: {
  keyframes: { wobble: {
    '0%,100%': { transform: 'rotate(-6deg)' },
    '50%':     { transform: 'rotate(6deg)' } } },
  animation: { wobble: 'wobble 1.1s infinite' }
}}
<!-- en el marcado -->
<span class="transition-transform duration-500
  ease-[cubic-bezier(.34,1.56,.64,1)]
  group-hover:-translate-y-10">
