Tailwind CSS

v3.4.17 · group-hover

Tailwind describe el movimiento en el mismo lugar que el diseño. Ideal para hover, foco y carga dentro de un componente.

Cómo lo implementé

Cada tarjeta es un group; sus hijos reaccionan con group-hover: y group-focus-visible:, así el teclado ve lo mismo que el mouse. La curva con rebote es un valor arbitrario y animate-wobble es un keyframe que registré en tailwind.config.

Este escenario no tiene una sola línea de CSS propio: todo son clases.

  • group-hover
  • duration-500
  • ease-[…]
  • animate-*
Pasa el cursor o enfoca con Tab
animate-ping animate-wobble, propio animate-bounce 
// js/config/tailwind.config.js
theme: { extend: {
  keyframes: { wobble: {
    '0%,100%': { transform: 'rotate(-6deg)' },
    '50%':     { transform: 'rotate(6deg)' } } },
  animation: { wobble: 'wobble 1.1s infinite' }
}}
<!-- en el marcado -->
<span class="transition-transform duration-500
  ease-[cubic-bezier(.34,1.56,.64,1)]
  group-hover:-translate-y-16">
