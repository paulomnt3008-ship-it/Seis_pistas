Para escenas en tres dimensiones sobre WebGL. Aquí combino dos librerías: Three.js dibuja y GSAP anima.

Cómo lo implementé

Una cámara en perspectiva, un icosaedro en malla de alambre y una nube de puntos sobre sus vértices. En cada fotograma la rotación se acerca a la posición del cursor con interpolación lineal, lo que da un seguimiento suave.

Un IntersectionObserver detiene el render cuando la pista sale de pantalla para ahorrar batería.

  • PerspectiveCamera
  • lerp

function frame() {
  rot.x += (target.y - rot.x) * 0.06; // lerp
  rot.y += (target.x - rot.y) * 0.06;
  group.rotation.set(rot.x, rot.y + t, 0);
  renderer.render(scene, camera);
  if (visible) requestAnimationFrame(frame);
}
